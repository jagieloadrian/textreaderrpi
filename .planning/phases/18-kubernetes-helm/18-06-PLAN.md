<objective>
Create an optional Ingress template that exposes the TextReaderRpi service externally over HTTP. The Ingress is disabled by default (`ingress.enabled: false`) and can be enabled by users who want external access to the application.

No TLS is configured in this phase (deferred to v1.3+).

The template routes requests to the internal Service created in 18-05.
</objective>

<acceptance_criteria>
1. Ingress template is syntactically valid.
2. When `ingress.enabled=false`, no Ingress resource is rendered.
3. When `ingress.enabled=true`, Ingress resource is rendered with correct backend service reference.
4. Ingress does not include TLS configuration.
5. Ingress uses the internal Service name for routing.
</acceptance_criteria>

### Task 1: Create Ingress template

**File location:** `.devops/helm/textreaderrpi/templates/ingress.yaml`

**Content:**

```yaml
{{- if .Values.ingress.enabled }}
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: {{ include "textreaderrpi.fullname" . }}
  labels:
    {{- include "textreaderrpi.labels" . | nindent 4 }}
  {{- with .Values.ingress.annotations }}
  annotations:
    {{- toYaml . | nindent 4 }}
  {{- end }}
spec:
  {{- if .Values.ingress.className }}
  ingressClassName: {{ .Values.ingress.className }}
  {{- end }}
  rules:
    {{- if .Values.ingress.host }}
    - host: {{ .Values.ingress.host | quote }}
      http:
        paths:
          - path: {{ .Values.ingress.path | default "/" }}
            pathType: {{ .Values.ingress.pathType | default "Prefix" }}
            backend:
              service:
                name: {{ include "textreaderrpi.fullname" . }}
                port:
                  number: {{ .Values.service.port }}
    {{- else }}
    - http:
        paths:
          - path: {{ .Values.ingress.path | default "/" }}
            pathType: {{ .Values.ingress.pathType | default "Prefix" }}
            backend:
              service:
                name: {{ include "textreaderrpi.fullname" . }}
                port:
                  number: {{ .Values.service.port }}
    {{- end }}
{{- end }}
```

**Explanation:**
- Gated by `ingress.enabled` (boolean, default false).
- Uses `networking.k8s.io/v1` API version (Kubernetes 1.19+).
- Routes to the internal Service by name.
- Optional `ingressClassName` (e.g., "traefik" for K3s, "nginx" for nginx-ingress).
- Optional hostname (if not set, Ingress routes all traffic to the service).
- No TLS (no `tls:` block).
- Path defaults to `/` (Prefix matching).

### Task 2: Update values.yaml with ingress config

Ensure `.devops/helm/textreaderrpi/values.yaml` includes:

```yaml
ingress:
  enabled: false
  className: ""  # e.g., "traefik" for K3s
  annotations: {}
  host: ""       # e.g., "textreader.local"
  path: /
  pathType: Prefix
```

**Explanation:**
- `enabled: false` by default (Ingress is opt-in).
- `className: ""` works with K3s Traefik by default. User can override.
- `host` is optional; if empty, Ingress routes all traffic to the service.
- No TLS configuration.

### Task 3: Render and verify

Run with Ingress disabled (default):
```bash
helm template textreaderrpi .devops/helm/textreaderrpi/ | grep "kind: Ingress"
```

Expected: no output (Ingress not rendered).

Run with Ingress enabled:
```bash
helm template textreaderrpi .devops/helm/textreaderrpi/ --set ingress.enabled=true | grep -A 20 "kind: Ingress"
```

Expected: Ingress resource with backend service reference.

Run with hostname:
```bash

```

Expected: line shows `host: textreader.local`.
