<objective>
Create the main Deployment template that:
- Uses a hardcoded `replicas: 1` (not configurable)
- Conditionally applies privileged mode + hostPath device mounts when `hardwareAccess.enabled: true`
- Injects `DISPLAY_TYPE=OFFLINE` env override when `hardwareAccess.enabled: false` to disable hardware access
- Loads all non-sensitive env vars from ConfigMap (to be created in 18-03)
- Loads sensitive vars (DB credentials) from Secret via `valueFrom.secretKeyRef` (to be created in 18-03)
- Injects `JAVA_TOOL_OPTIONS: -Xmx220m` from ConfigMap
- Defines liveness and readiness HTTP probes on `/health` and `/health/ready`
- Mounts PersistentVolumeClaims for `/data` (H2 database) and `/app/logs`

The Deployment uses the image specified in values.yaml with pull policy from values.yaml.
</objective>

<acceptance_criteria>
1. Deployment YAML is syntactically valid (no helm template errors).
2. When `helm template` is run, the output contains `replicas: 1` (hardcoded, not a variable).
3. When `hardwareAccess.enabled=true`, the template renders `privileged: true` and two hostPath volume mounts.
4. When `hardwareAccess.enabled=false`, the template renders env override `DISPLAY_TYPE=OFFLINE` and no device mounts.
5. Liveness and readiness probes are present with correct paths and timing.
6. CPU/memory requests and limits are sensible (e.g., 100m/128Mi request, 500m/256Mi limit).
</acceptance_criteria>

### Task 1: Create .devops/helm/textreaderrpi/templates/deployment.yaml

**File location:** `.devops/helm/textreaderrpi/templates/deployment.yaml`

Structure (pseudo-template):

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: {{ include "textreaderrpi.fullname" . }}
  labels:
    {{- include "textreaderrpi.labels" . | nindent 4 }}
spec:
  replicas: 1  # Hardcoded: Pi hardware cannot support multiple replicas with shared SPI/I2C and file DB
  selector:
    matchLabels:
      {{- include "textreaderrpi.selectorLabels" . | nindent 6 }}
  template:
    metadata:
      annotations:
        {{- toYaml .Values.podAnnotations | nindent 8 }}
      labels:
        {{- include "textreaderrpi.selectorLabels" . | nindent 8 }}
    spec:
      serviceAccountName: {{ include "textreaderrpi.serviceAccountName" . }}
      securityContext:
        {{- if .Values.hardwareAccess.enabled }}
        privileged: true
        {{- end }}
      
      containers:
      - name: textreaderrpi
        image: "{{ .Values.image.repository }}:{{ .Values.image.tag }}"
        imagePullPolicy: {{ .Values.image.pullPolicy }}
        
        ports:
        - containerPort: 8080
          name: http
        
        envFrom:
        - configMapRef:
            name: textreaderrpi-config
        
        env:
        {{- if not .Values.hardwareAccess.enabled }}
        - name: DISPLAY_TYPE
          value: "OFFLINE"
        {{- end }}
        - name: DATABASE_USER
          valueFrom:
            secretKeyRef:
              name: textreaderrpi-secret
              key: DATABASE_USER
        - name: DATABASE_PASSWORD
          valueFrom:
            secretKeyRef:
              name: textreaderrpi-secret
              key: DATABASE_PASSWORD
        
        livenessProbe:
          httpGet:
            path: /health
            port: http
          initialDelaySeconds: 20
          periodSeconds: 30
          timeoutSeconds: 5
          failureThreshold: 3
        
        readinessProbe:
          httpGet:
            path: /health/ready
            port: http
          initialDelaySeconds: 20
          periodSeconds: 30
          timeoutSeconds: 5
          failureThreshold: 3
        
        resources:
          requests:
            cpu: 100m
            memory: 128Mi
          limits:
            cpu: 500m
            memory: 256Mi
        
        volumeMounts:
        - name: data
          mountPath: /data
        - name: logs
          mountPath: /app/logs
        {{- if .Values.hardwareAccess.enabled }}
        - name: spidev
          mountPath: /dev/spidev0.0
        - name: i2c
          mountPath: /dev/i2c-1
        {{- end }}
      
      volumes:
      - name: data
        persistentVolumeClaim:
          claimName: {{ include "textreaderrpi.fullname" . }}-data
      - name: logs
        persistentVolumeClaim:
          claimName: {{ include "textreaderrpi.fullname" . }}-logs
      {{- if .Values.hardwareAccess.enabled }}
      - name: spidev
        hostPath:
          path: /dev/spidev0.0
          type: CharDevice
      - name: i2c
        hostPath:
          path: /dev/i2c-1
          type: CharDevice
      {{- end }}
      
      nodeSelector:
        {{- toYaml .Values.nodeSelector | nindent 8 }}
```

Key points:
- `replicas: 1` is hardcoded (not `.Values.replicas`).
- `securityContext.privileged: true` only when `hardwareAccess.enabled: true`.
- Device mounts only when hardware access is enabled.
- `DISPLAY_TYPE=OFFLINE` injected as env override when hardware access is disabled.
- Uses `{{ include "textreaderrpi.fullname" . }}` and `{{ include "textreaderrpi.labels" . }}` helpers (to be created in 18-07).
- Probes use `/health` (liveness) and `/health/ready` (readiness) with 20s initial delay.

### Task 2: Implement helper functions

**File location:** `.devops/helm/textreaderrpi/templates/_helpers.tpl`

**Content:**

```yaml
{{/*
Expand the name of the chart.
*/}}
{{- define "textreaderrpi.name" -}}
{{- default .Chart.Name .Values.nameOverride | trunc 63 | trimSuffix "-" }}
{{- end }}

{{/*
Create a default fully qualified app name.
*/}}
{{- define "textreaderrpi.fullname" -}}
{{- if .Values.fullnameOverride }}
{{- .Values.fullnameOverride | trunc 63 | trimSuffix "-" }}
{{- else }}
{{- $name := default .Chart.Name .Values.nameOverride }}
{{- if contains $name .Release.Name }}
{{- .Release.Name | trunc 63 | trimSuffix "-" }}
{{- else }}
{{- printf "%s-%s" .Release.Name $name | trunc 63 | trimSuffix "-" }}
{{- end }}
{{- end }}
{{- end }}

{{/*
Create chart name and version as used by the chart label.
*/}}
{{- define "textreaderrpi.chart" -}}
{{- printf "%s-%s" .Chart.Name .Chart.Version | replace "+" "_" | trunc 63 | trimSuffix "-" }}
{{- end }}

{{/*
Common labels
*/}}
{{- define "textreaderrpi.labels" -}}
helm.sh/chart: {{ include "textreaderrpi.chart" . }}
{{ include "textreaderrpi.selectorLabels" . }}
{{- if .Chart.AppVersion }}
app.kubernetes.io/version: {{ .Chart.AppVersion | quote }}
{{- end }}
app.kubernetes.io/managed-by: {{ .Release.Service }}
{{- end }}

{{/*
Selector labels
*/}}
{{- define "textreaderrpi.selectorLabels" -}}
app.kubernetes.io/name: {{ include "textreaderrpi.name" . }}
app.kubernetes.io/instance: {{ .Release.Name }}
{{- end }}

{{/*
Create the name of the service account to use
*/}}
{{- define "textreaderrpi.serviceAccountName" -}}
{{- if .Values.serviceAccount.create }}
{{- default (include "textreaderrpi.fullname" .) .Values.serviceAccount.name }}
{{- else }}
{{- default "default" .Values.serviceAccount.name }}
{{- end }}
{{- end }}
```

Note: This creates the helpers used by the deployment template. Ensure it's at `.devops/helm/textreaderrpi/templates/_helpers.tpl`.
