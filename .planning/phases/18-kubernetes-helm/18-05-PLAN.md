<objective>
Create the Service, ServiceAccount, and RBAC (Role + RoleBinding) templates:

- **Service**: ClusterIP service exposing port 8080 internally within the cluster so other workloads can reach the app.
- **ServiceAccount**: A dedicated identity for the pod (instead of using `default`). Gated by `rbac.create: true` in values.yaml.
- **Role**: Minimal permissions for the pod to list/get Pods in its own namespace (needed for self-discovery or monitoring). Scoped to namespace-level (Role, not ClusterRole).
- **RoleBinding**: Binds the Role to the ServiceAccount so pods using the SA get the Role's permissions.

All four resources are gated by `rbac.create: true` (default is true, but can be disabled to use the cluster's default ServiceAccount).
</objective>

<acceptance_criteria>
1. Service YAML is valid and exposes port 8080.
2. ServiceAccount template is valid and uses the correct naming convention.
3. Role template defines minimal permissions (`get`, `list` on `pods`).
4. RoleBinding template correctly binds Role to ServiceAccount.
5. When `rbac.create=false`, none of these RBAC resources are rendered.
6. When `rbac.create=true`, all four resources are rendered.
7. Deployment spec already references the ServiceAccount (created in 18-02).
</acceptance_criteria>

### Task 3: Create Role template

**File location:** `.devops/helm/textreaderrpi/templates/role.yaml`

**Content:**

```yaml
{{- if .Values.rbac.create }}
apiVersion: rbac.authorization.k8s.io/v1
kind: Role
metadata:
  name: {{ include "textreaderrpi.fullname" . }}-role
  labels:
    {{- include "textreaderrpi.labels" . | nindent 4 }}
rules:
  - apiGroups: [""]
    resources: ["pods"]
    verbs: ["get", "list"]
{{- end }}
```

**Explanation:**
- Scoped to **Role** (namespace-level), not ClusterRole.
- Permissions: `get` and `list` on `pods` resource.
- Gated by `rbac.create: true`.
- Allows the pod to query pod information in its own namespace (useful for monitoring/self-discovery if the app needs it).

### Task 4: Create RoleBinding template

**File location:** `.devops/helm/textreaderrpi/templates/rolebinding.yaml`

**Content:**

```yaml
{{- if .Values.rbac.create }}
apiVersion: rbac.authorization.k8s.io/v1
kind: RoleBinding
metadata:
  name: {{ include "textreaderrpi.fullname" . }}-rolebinding
  labels:
    {{- include "textreaderrpi.labels" . | nindent 4 }}
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: Role
  name: {{ include "textreaderrpi.fullname" . }}-role
subjects:
  - kind: ServiceAccount
    name: {{ include "textreaderrpi.fullname" . }}-sa
    namespace: {{ .Release.Namespace }}
{{- end }}
```

**Explanation:**
- Binds the Role to the ServiceAccount.
- References the Role and ServiceAccount by name.
- Namespace-scoped (uses `{{ .Release.Namespace }}`).
- Gated by `rbac.create: true`.
