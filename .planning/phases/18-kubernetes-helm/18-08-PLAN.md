### Task 5: (Optional) Add CI workflow

Create `.github/workflows/helm-lint.yml`:

```yaml
name: Helm Lint

on:
  pull_request:
    paths:
      - '.devops/helm/textreaderrpi/**'
      - '.github/workflows/helm-lint.yml'
  push:
    branches:
      - main
    paths:
      - '.devops/helm/textreaderrpi/**'

jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Set up Helm
        uses: azure/setup-helm@v3
        with:
          version: 'latest'
      
      - name: Helm Lint
        run: |
          helm lint .devops/helm/textreaderrpi/
      
      - name: Helm Template (default)
        run: |
          helm template textreaderrpi .devops/helm/textreaderrpi/
      
      - name: Helm Template (hardwareAccess=true)
        run: |
          helm template textreaderrpi .devops/helm/textreaderrpi/ --set hardwareAccess.enabled=true
      
      - name: Helm Template (rbac.create=false)
        run: |
          helm template textreaderrpi .devops/helm/textreaderrpi/ --set rbac.create=false
```

This CI job ensures:
- Helm lint passes on every PR
- Templates render correctly with various flag combinations
- Future changes to the chart are validated automatically
