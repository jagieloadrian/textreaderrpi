### Task 2: Create .devops/helm/textreaderrpi/values.yaml

Copy the structure below, which defines all configuration knobs used by templates (to be created in later plans):

```yaml
# Image configuration
image:
  repository: textreaderrpi
  tag: latest
  pullPolicy: Never  # Assumes image is pre-loaded on node; user overrides for registry deploys

# Hardware access toggle
hardwareAccess:
  enabled: false

# JVM heap cap
JAVA_TOOL_OPTIONS: "-Xmx220m"

# Deployment replicas (hardcoded to 1 — not configurable)
replicas: 1

# Persistence volumes
persistence:
  data:
    enabled: true
    storageClass: ""  # Uses default storage class (e.g., "local-path" on K3s)
    size: 1Gi
  logs:
    enabled: true
    storageClass: ""
    size: 500Mi

# Service configuration
service:
  type: ClusterIP
  port: 8080
  targetPort: 8080

# Ingress configuration (disabled by default)
ingress:
  enabled: false
  className: ""
  annotations: {}
  host: ""
  path: /
  pathType: Prefix

# RBAC
rbac:
  create: true

# Node selection (empty by default; user can set kubernetes.io/arch: arm64 to pin to Pi nodes)
nodeSelector: {}

# Pod annotations
podAnnotations: {}

# Security context defaults (will be overridden by securityContext in deployment template)
securityContext: {}
```

Ensure the file is at `.devops/helm/textreaderrpi/values.yaml`.
