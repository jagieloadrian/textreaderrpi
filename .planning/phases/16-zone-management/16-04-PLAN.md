</objective>

  <action>
  Modify ONLY the `addZone(e)` function. Do not touch any other function.

  The existing function body has this structure in its try block:

    if (response.status === 201) {
      showToast("Zone added successfully.", "success");
      setTimeout(() => { window.location.reload(); }, 200);
    } else if (response.status === 422) {
      const msg = await response.text();
      resultDiv.textContent = msg;
    } else if (response.status === 409) {
      resultDiv.textContent = "A zone with this name is already registered.";
    } else {
      const msg = await response.text();
      resultDiv.textContent = msg || "Could not add zone.";
    }

  Replace it with:

    if (response.status === 201) {
      showToast("Zone added successfully.", "success");
      const form = document.getElementById("addZoneForm");
      if (form) form.reset();
      setTimeout(() => { window.location.reload(); }, 200);
    } else if (response.status === 422) {
      const msg = await response.text();
      showToast(msg || "Validation error.", "error");
    } else if (response.status === 409) {
      showToast("A zone with this name is already registered.", "error");
    } else {
      const msg = await response.text();
      showToast(msg || "Could not add zone.", "error");
    }

  The `resultDiv` variable and its `getElementById("addZoneResult")` assignment at the top of `addZone()` becomes unused after this change — remove the lines that declare and assign `resultDiv` (the `const resultDiv = ...` line and the `if (!resultDiv) return;` guard) since the div is no longer referenced.
