## OBS-03 Interaction Contract

The only visual behavior change in Phase 12 is ensuring the HTML error page is served by browsers instead of the SwaggerUI catch-all.

**Before fix (if broken):** `GET /does-not-exist` in a browser receives a SwaggerUI JSON response.

**After fix:** `GET /does-not-exist` in a browser receives the HTML 404 error page from `ErrorPage.kt`.

**Mechanism:** Move `swaggerUI(path = "openapi")` to the last position in the `routing {}` block in `Routing.kt`. No template changes. No copy changes.

**Verification criterion (SC-3):** A browser navigating to `/does-not-exist` must render the HTML page with heading "Error 404" and body "Page not found" and a "Back to home" link — not a JSON payload.

`prefersHtml()` logic (already implemented): returns `true` when `Accept` header contains `text/html` and path does not start with `/api`. This is unchanged.
