<objective>
Build the status-page live feed widget (LIVE-02): a new "Live Feed" `<article>` at the TOP of `StatusPage.kt` containing `#live-text` and `#live-meta` elements, a new `live-feed.js` static file that opens an `EventSource` to `/api/v1/live` and updates those elements via `textContent` on each named `display` event, and a script tag that loads `live-feed.js` on the status page ONLY (not in `BaseLayout.kt`).
