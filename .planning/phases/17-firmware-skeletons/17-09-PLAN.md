# Plan 17-09: Unify flash workflow — ESP32 ESP-IDF + CMake, Pico flash target

## Objective

Replace PlatformIO/Arduino on ESP32 with a native ESP-IDF CMake project so both platforms
share the same build/flash interface:

```bash
# Pico
cmake -B firmware/pico/build -DPICO_BOARD=pico_w -S firmware/pico
cmake --build firmware/pico/build -j$(nproc)
cmake --build firmware/pico/build --target flash   # picotool

# ESP32
cmake -B firmware/esp32/build -DIDF_TARGET=esp32 \
      -DCMAKE_TOOLCHAIN_FILE=$IDF_PATH/tools/cmake/toolchain-esp32.cmake \
      -S firmware/esp32
cmake --build firmware/esp32/build -j$(nproc)
cmake --build firmware/esp32/build --target flash  # esptool (IDF built-in)
```

## Artifacts this phase produces

- `firmware/esp32/CMakeLists.txt` — IDF top-level project
- `firmware/esp32/sdkconfig.defaults` — Kconfig defaults
- `firmware/esp32/main/CMakeLists.txt` — main component registration
- `firmware/esp32/main/main.c` — app_main entry point (FreeRTOS)
- `firmware/esp32/main/config.h` — same constants as before
- `firmware/esp32/main/ws_client.c/.h` — esp_websocket_client wrapper
- `firmware/esp32/main/json_parser.c/.h` — cJSON based (same API as Pico)
- `firmware/esp32/main/captive_portal.c/.h` — esp_wifi AP + esp_http_server + NVS
- `firmware/esp32/main/ota.c/.h` — esp_ota_ops (triggered by WS command)
- `firmware/esp32/main/driver/display.h` — unchanged 3-function interface
- `firmware/esp32/main/driver/max7219.c/.h` — spi_master based, same logic as Pico
- `flash` CMake custom target in `firmware/pico/CMakeLists.txt`

    reply A=192.168.4.1 for all queries). Start HTTP server: GET / → form HTML,
    POST /save → parse ssid+pass from body, nvs_set_str, nvs_commit, esp_restart().

  firmware/esp32/main/ota.c:
    trigger_ota(): esp_ota_begin, serve binary via TCP/3232 (or just esp_restart
    into OTA partition if using esp_https_ota). ota_init() is a no-op (OTA handled
    on-demand via WS command). Keep trigger_ota() signature for json_parser.c.

  firmware/esp32/main/driver/max7219.c:

    Same register logic as firmware/pico/src/driver/max7219.c: MAX7219_REG_*, 
    spi_write_reg(), max7219_init(), max7219_clear(), max7219_display_text().
    display_text() wrapper maps (text, effect, speed, blinkPeriod, fadeSteps) to

  In firmware/pico/CMakeLists.txt, after the picowota_build_combined(textreader) line, add:

    if(PICOTOOL_EXEC)
        add_custom_target(flash
            DEPENDS textreader
            COMMAND ${PICOTOOL_EXEC} load --force "${CMAKE_BINARY_DIR}/textreader_combined.uf2"
            COMMENT "Flashing via picotool"
        )
    else()
        add_custom_target(flash
            COMMAND ${CMAKE_COMMAND} -E echo "picotool not found — copy textreader_combined.uf2 manually"
        )
    endif()

  In .github/workflows/firmware-ci.yml, replace the esp32 job (pio run) with:
    - name: Install ESP-IDF
      run: |
        git clone --depth 1 --branch v5.2.1 https://github.com/espressif/esp-idf.git $HOME/esp-idf
        $HOME/esp-idf/install.sh esp32
    - name: Build ESP32 (cmake)
      run: |
        . $HOME/esp-idf/export.sh
        cmake -B firmware/esp32/build -DIDF_TARGET=esp32 \
              -DCMAKE_TOOLCHAIN_FILE=$IDF_PATH/tools/cmake/toolchain-esp32.cmake \
              -S firmware/esp32
        cmake --build firmware/esp32/build -j$(nproc)
    - name: Upload ESP32 artifact
