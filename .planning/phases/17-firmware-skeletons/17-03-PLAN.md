<objective>
Create the RPi Pico W / Pico 2W firmware skeleton (`firmware/pico/`, C, pico-sdk). The firmware connects to WiFi via CYW43, opens a Mongoose WebSocket to the server's `/ws/zone/{id}` endpoint, parses incoming FirmwareMessage JSON with cJSON, and renders text with SCROLL/BLINK/REVERSE/FADE effects on a MAX7219 LED matrix via SPI. It reconnects on drop, supports OTA via picowota, and serves a captive portal for first-boot WiFi provisioning (FW-01, D-01 through D-24).

Purpose: This is one of the two deliverable firmware projects. MAX7219 is the reference driver (the only display in the success criteria); other drivers are stubbed for a later phase. The project must configure and compile in CI without hardware (D-18); physical flash+scroll is a human-verify checkpoint (17-06).
Output: A complete `firmware/pico/` CMake project — config, WS client, JSON parser, MAX7219 driver, 5x8 font, OTA trigger, captive portal, README.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server → firmware (WebSocket) | Server-pushed JSON parsed on the MCU |
| WiFi client → captive portal (AP mode) | First-boot user submits SSID/password over local AP HTTP |
| OTA pusher → device flash | A new firmware binary is written to flash via picowota |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-02 | Tampering | cJSON parse of WS frame | mitigate | parse_and_display null-checks cJSON root and type-guards each field before use; malformed JSON is dropped, not faulted |
| T-17-03 | Tampering | OTA binary write | mitigate | picowota verifies CRC before flashing and runs flash writes from SRAM (Pitfall 2), preventing brick on bad download; LAN-only access accepted (home network, D-02) |
| T-17-04 | Information Disclosure | captive portal credentials | mitigate | Portal served only in AP mode with no internet uplink; credentials written to local flash, never transmitted elsewhere |
| T-17-07 | Denial of Service | speed integer used as delay | mitigate | speed clamped to max(1, min(speed, 5000)) before delay to prevent overflow/hang (research Security Domain) |
| T-17-SC | Tampering | C/C++ library sourcing | mitigate | Mongoose copied from pinned 7.22 raw URL; cJSON FetchContent pinned to v1.7.19; picowota pinned submodule — all are established repos (research Package Legitimacy Audit, no npm gate applies) |
</threat_model>
