<objective>
Create the ESP32 firmware skeleton (`firmware/esp32/`, C++, Arduino + PlatformIO). It connects to WiFi, opens an ArduinoWebsockets client to the server's `/ws/zone/{id}` endpoint, parses incoming FirmwareMessage JSON with ArduinoJson, and renders text with SCROLL/BLINK/REVERSE/FADE on a MAX7219 LED matrix via MD_Parola/MD_MAX72XX. It reconnects on drop, supports OTA via ArduinoOTA, and provisions WiFi via the WiFiManager captive portal (FW-02, D-04, D-05, D-10, D-11, D-15, D-20, D-22, D-23, D-24).

Purpose: The second deliverable firmware project, mirroring the Pico's 3-function driver interface and wire protocol so both devices register as zones identically. MAX7219 is the reference driver. The project must resolve dependencies and compile in CI (pio run, D-18); physical flash+render is a human-verify checkpoint (17-06).
Output: A complete `firmware/esp32/` PlatformIO project — platformio.ini, config, WS client, JSON parser, MAX7219 driver, OTA, captive portal, README.
</objective>
