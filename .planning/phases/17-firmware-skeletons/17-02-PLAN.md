<objective>
Accept the three optional timing parameters (speed, blinkPeriod, fadeSteps) on the POST /api/v1/text request body, validate they are positive integers (or absent), and forward them to ScreenDriverService.displayImmediate so they reach firmware zones. For local and network zones the values are silently ignored (D-13).

Purpose: This is the API surface that lets a user (or scheduler) set firmware animation timing per request. Validation MUST live only in RequestValidators per the project coding rule — never inline in the route handler.
Output: Extended TextRequest DTO, positive-integer validators, updated TextRoutes call, plus validation and API route tests.
</objective>
