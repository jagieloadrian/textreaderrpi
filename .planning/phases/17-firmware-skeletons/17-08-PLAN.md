  <action>
    All 5 drivers implement the D-07 interface: display_init(), display_clear(),
    display_text(const char* text, const char* effect, int speed_ms).
    All effects: SCROLL, BLINK, REVERSE, FADE. Use Adafruit GFX ecosystem (D-05).

    SSD1306 (Adafruit_SSD1306, I2C, addr 0x3C, 128x64):
    display_init: Adafruit_SSD1306 display(128, 64, &Wire); display.begin(SSD1306_SWITCHCAPVCC, 0x3C).
    display_clear: display.clearDisplay(); display.display().
    display_text: use display.setTextSize(1), display.setTextColor(SSD1306_WHITE),
    display.setCursor(0,0), display.print(text), display.display().
    SCROLL: use display.startscrollleft(0x00, 0x0F) hardware scroll command —
    set scroll speed via the delay between start and stop scroll (speed_ms controls
    how long the scroll runs before stopping); alternatively redraw manually each
    speed_ms tick shifting the cursor x offset.
    BLINK: toggle display.invertDisplay(true/false) with delay(speed_ms) for 6 cycles.
    REVERSE: reverse the text string (local char buf), display.print(reversed).
    FADE: use display.dim(true/false) — dim is binary on Adafruit SSD1306; ramp
    contrast via Wire.write of 0x81 + fadeSteps-stepped value using the raw I2C
    commands sendDisplayCommand helper.

    SSD1309 (Adafruit_SSD1306-compatible, I2C, 128x64): SSD1309 is register-compatible
    with SSD1306. Use Adafruit_SSD1306 with the same constructor and init. The
    ssd1309.cpp file instantiates its own Adafruit_SSD1306 object so both drivers
    can coexist in the source tree (only one compiles). Effects identical to SSD1306.

    SSD1327 (Adafruit_SSD1327 or raw I2C, 128x128 grayscale):
    Include Adafruit_SSD1327 if available in lib_deps (add to platformio.ini:
    adafruit/Adafruit SSD1327). display_init: Adafruit_SSD1327 display(128, 128, &Wire).
    display.begin(0x3D). display_clear: display.clearDisplay(); display.display().
    display_text: setTextSize(1), setTextColor(0x0F) (max brightness in 4bpp), print.
    FADE: ramp setTextColor from 0x01 to 0x0F in steps and redraw.
    BLINK/SCROLL/REVERSE: same pattern as SSD1306.

    SH1106 (U8g2 or Adafruit-compatible 132x64 OLED, SPI):
    No Adafruit_SH1106 is in D-05 lib_deps. Use U8g2 library (add to lib_deps:
    olikraus/U8g2). Instantiate U8G2_SH1106_128X64_NONAME_F_4W_HW_SPI u8g2(
    U8G2_R0, CS_PIN, DC_PIN, RESET_PIN). display_init: u8g2.begin().
    display_clear: u8g2.clearDisplay(); u8g2.sendBuffer().
    display_text: u8g2.clearBuffer(); u8g2.setFont(u8g2_font_5x8_tf);
    u8g2.drawStr(0, 8, text); u8g2.sendBuffer().
    SCROLL: redraw with x-offset shift per speed_ms tick.
    BLINK: u8g2.setContrast(0) / u8g2.setContrast(255) alternating.
    REVERSE/FADE: same pattern.

    HT16K33 (Adafruit_LEDBackpack, I2C, 0x70 — 8x8 LED matrix):
    Include Adafruit_LEDBackpack (already transitive via Adafruit GFX). Instantiate
    Adafruit_8x8matrix matrix. display_init: matrix.begin(0x70).
    display_clear: matrix.clear(); matrix.writeDisplay().
    display_text: render the first 8 chars into the 8x8 grid using font5x8 column
    bytes mapped to matrix.setRow(row, byte). For SCROLL: shift columns each
    speed_ms tick and call writeDisplay(). BLINK: matrix.setBrightness(0) /
    matrix.setBrightness(15) alternating with delay(speed_ms).
    FADE: ramp matrix.setBrightness(0..15) with delay(speed_ms/16).
    REVERSE: reversed string.

    Add to platformio.ini lib_deps the new libraries needed:
    adafruit/Adafruit SSD1327, olikraus/U8g2, adafruit/Adafruit LED Backpack Library.
  </action>

    ST7735 (Adafruit_ST7735, 128x160 SPI TFT):
    display_init: Adafruit_ST7735 tft(CS_PIN, DC_PIN, RST_PIN); tft.initR(INITR_BLACKTAB).
    display_clear: tft.fillScreen(ST77XX_BLACK).
    display_text: tft.setTextSize(1); tft.setTextColor(ST77XX_WHITE); tft.setCursor(0,0); tft.print(text).
    SCROLL: hardware scroll via tft.scrollTo(offset) each speed_ms tick; or manual
    redraw at incremented x offset. BLINK: tft.enableDisplay(true/false) if available;
    else alternate fillScreen(BLACK)/print cycle. REVERSE: reversed string.
    FADE: tft has no brightness PWM — use dimming approximation: fill background with
    progressively lighter grey (0x0000→0x3186→0x7BEF→0xFFFF in steps) and redraw text.

    ST7789 (Adafruit_ST7789, 240x240 SPI TFT):
    display_init: Adafruit_ST7789 tft(CS_PIN, DC_PIN, RST_PIN); tft.init(240, 240).
    Same display_text/effects pattern as ST7735 but 240px width.

    ILI9225 (176x220 SPI TFT): Adafruit_GFX does not have a first-party ILI9225
    driver. Use TFT_22_ILI9225 library (add lib_deps: Nkawu/TFT_22_ILI9225 or
    equivalent PlatformIO registry entry). Instantiate TFT_22_ILI9225 tft(RST_PIN,
    RS_PIN, CS_PIN, MOSI_PIN, CLK_PIN). tft.begin(); tft.setOrientation(0).
    display_clear: tft.fillScreen(COLOR_BLACK). display_text: tft.setTextSize(1);
    tft.drawText(0, 0, text, COLOR_WHITE, COLOR_BLACK, 1). Effects: same TFT pattern.

    PCD8544 (84x48 SPI monochrome — Nokia 5110):
    Use Adafruit PCD8544 library (add lib_deps: adafruit/Adafruit PCD8544 Nokia 5110
    LCD Library). Instantiate Adafruit_PCD8544 display(CLK_PIN, DIN_PIN, DC_PIN,
    CS_PIN, RST_PIN). display_init: display.begin(); display.setContrast(50).
    display_clear: display.clearDisplay(); display.display().
    display_text: display.print(text); display.display(). SCROLL: manual x-offset
    redraw each speed_ms tick. BLINK: display.display()/clearDisplay() alternating.
    REVERSE: reversed string. FADE: ramp setContrast(0..63) across fadeSteps steps.

    SSD1680 (GxEPD2, 2.13" e-paper 250x122 SPI):
    Use GxEPD2_BW<GxEPD2_213_B74, GxEPD2_213_B74::HEIGHT> display(CS_PIN, DC_PIN,
    RST_PIN, BUSY_PIN). display_init: display.init(115200). display_clear:
    display.setFullWindow(); display.firstPage(); do { display.fillScreen(GxEPD_WHITE); }
    while (display.nextPage()). display_text: display.setFullWindow();
    display.setFont(&FreeMonoBold9pt7b); display.setTextColor(GxEPD_BLACK);
    display.firstPage(); do { display.fillScreen(GxEPD_WHITE); display.setCursor(0,18);
    display.print(text); } while (display.nextPage()). Effects: e-paper is too slow
    for smooth SCROLL — do a full refresh per 8-char shift (send full page each tick,
    rate-limited by speed_ms). BLINK: alternate full white/black refresh. REVERSE:
    single refresh with reversed text. FADE: not applicable — do 2 blink cycles.

    display.cpp update (D-06 compile-time routing):
    Replace the current unconditional delegation to max7219_* with a preprocessor
    chain. Include all driver headers conditionally. The three functions
    (display_init, display_clear, display_text) each contain an if/elif chain:
      #if defined(DISPLAY_DRIVER_SSD1306)
        // call ssd1306_* or instantiated Adafruit object from ssd1306.cpp
      #elif defined(DISPLAY_DRIVER_SSD1309)
        ...
      #elif defined(DISPLAY_DRIVER_MAX7219)
        max7219_init(); / max7219_clear(); / max7219_display_text(...)
      #endif
    Since each driver's .cpp file holds a static display object, display.cpp only
    needs to forward-declare the three functions from each driver. Simplest pattern:
    each driver exposes its own display_init_DRIVERNAME / display_clear_DRIVERNAME /
    display_text_DRIVERNAME symbols, and display.cpp aliases the active one via the
    preprocessor. Alternatively — and simpler — each driver .cpp implements
    display_init/display_clear/display_text directly (same symbol names), and
    display.cpp becomes a thin dispatcher that is only compiled when no driver is
    selected (fallback no-op). The build system (platformio.ini) controls which
    .cpp files are compiled via build_src_filter; add the per-driver exclude pattern
    or use build_flags -DDISPLAY_DRIVER_XXX=1 to guard each driver with
    #ifdef DISPLAY_DRIVER_XXX at the top of the .cpp — files that don't match
    compile to empty translation units. This avoids duplicate symbol linker errors.
    Add #ifndef DISPLAY_DRIVER_GUARD at the top of each driver .cpp and .h.

    platformio.ini update — multi-board + multi-driver envs:
    Keep the existing [env:esp32dev] as the default (MAX7219, esp32dev board).
    Add a [env:base] section with the common settings (platform, framework,
    lib_deps — all libraries from the original esp32dev plus the new ones:
    adafruit/Adafruit SSD1327, olikraus/U8g2, adafruit/Adafruit LED Backpack Library,
    adafruit/Adafruit ST7735 and ST7789, adafruit/Adafruit PCD8544 Nokia 5110,
    zinggjm/GxEPD2, Nkawu/TFT_22_ILI9225). Then add one [env:] per board variant
    that has WiFi, all extending [env:base] via extends = base:

      [env:esp32-s3]   board = esp32-s3-devkitc-1   build_flags = ... -DDISPLAY_DRIVER_MAX7219
      [env:esp32-s2]   board = esp32-s2-saola-1      build_flags = ... -DDISPLAY_DRIVER_MAX7219
      [env:esp32-c3]   board = esp32-c3-devkitm-1    build_flags = ... -DDISPLAY_DRIVER_MAX7219
      [env:esp32-c2]   board = esp32-c2-devkitm-1    build_flags = ... -DDISPLAY_DRIVER_MAX7219
      [env:esp32-h2]   board = esp32-h2-devkitm-1    build_flags = ... -DDISPLAY_DRIVER_MAX7219

    Each board env defaults to MAX7219. The user changes build_flags in their chosen
    env (or creates a local override env) to switch display. Note in a comment that
    ESP32-H2 has no WiFi (only 802.15.4/BT) — if WiFi is required use S2/S3/C3/C2.
    ESP32-C2 and H2 have no hardware floating point; flag with a comment.

    Add the new libraries to the shared lib_deps block and confirm none duplicate
    existing entries.
