<objective>
Extend the server-side wire protocol so firmware zones receive optional effect-timing values (speed, blinkPeriod, fadeSteps). This adds the three nullable Int fields to FirmwareMessage with kotlinx.serialization configured to OMIT them when null, extends the ZoneDriver.send() interface to carry the timing values, and threads them through ZoneRegistry and ScreenDriverService down to FirmwareZoneDriver.

Purpose: Firmware devices (Phase 17 Pico/ESP32) read these fields to drive SCROLL/BLINK/FADE animation timing. The protocol must be backward-compatible — existing firmware zones and all local/network zones are unaffected because the new fields default to null and are omitted from JSON when absent (D-11, D-12).
Output: Extended FirmwareMessage, ZoneDriver interface, all three ZoneDriver implementations, ZoneRegistry, ScreenDriverService, plus serialization and driver tests.
</objective>
