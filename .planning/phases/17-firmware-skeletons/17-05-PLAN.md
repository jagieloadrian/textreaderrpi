<objective>
Add a GitHub Actions workflow that build-checks both firmware projects on every push without requiring physical hardware, and publishes the flashable artifacts (.uf2 for Pico W / Pico 2W, .bin/.elf for ESP32) as downloadable Actions artifacts so users can flash without a local toolchain (D-18).

Purpose: This is the automated verification gate for FW-01 and FW-02 — the firmware C/C++ code cannot be exercised by the Kotlin/Gradle test suite, so compile-checking in CI is how we prove the projects build. It runs alongside the existing ci.yml (Gradle) without modifying it.
Output: `.github/workflows/firmware-ci.yml` with a pico job (pico_w + pico2_w) and an esp32 job, both uploading artifacts.
</objective>
