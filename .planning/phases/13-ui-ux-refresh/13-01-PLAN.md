# Plan 13-01: Foundation — CSS, BaseLayout, JS Scaffold

## Objective

Create the static asset foundation for the Material Design 3 UI refresh:
1. `custom.css` — MD3 color tokens, PicoCSS variable overrides, aside+main flex layout, mobile responsive rules, @keyframes effect preview animations, zone status badge styles
