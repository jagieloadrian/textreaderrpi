<objective>
Fix the SPI packet direction bug in Max7219Matrix so text scrolls left-to-right on the physical chain, extract buildPacket as a testable pure function, remove the broken size guards in write() and displayStatic(), and add two byte-level unit tests that lock the fix in.

Purpose: The current render() uses `d` directly as the bitmap column group index, making d=0 (SPI first slot) control the physically rightmost module. This is backwards. The fix applies `physicalD = numDevices - 1 - d` inside buildPacket to reverse the column-to-SPI-slot mapping. Extracting buildPacket as an internal pure function (no SPI dependency) is what makes unit testing possible without Pi4J.

Output:
- Max7219Matrix.kt: buildPacket() extracted as internal function, physicalD fix applied, render() delegates to buildPacket, write() and displayStatic() guards removed
- Max7219MatrixTest.kt: two new tests — byte-exact for numDevices=1 and structural direction test for numDevices=2
</objective>
