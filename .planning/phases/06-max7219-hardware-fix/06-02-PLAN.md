<objective>
Introduce AbstractDisplayDriver as the shared base class for the three hardware display drivers, extract the duplicated job/lastMessage/lastError fields and stop()/status() implementations into it, and refactor Max7219Matrix, LcdDisplay, and OledDisplay to extend it. OfflineDisplayDriver is explicitly excluded per D-06.

Purpose: All three hardware drivers carry byte-for-byte identical boilerplate (5 fields + 2 method bodies). Lifting this into AbstractDisplayDriver eliminates the duplication, makes the driver layer DRY, and ensures future changes to status() or stop() are made in one place only.

Output:
- AbstractDisplayDriver.kt: new abstract class in com.anjo.driver package
- Max7219Matrix.kt: extends AbstractDisplayDriver, adds isHardwareAvailable(), removes duplicated fields and methods, removes import kotlinx.coroutines.Job
- LcdDisplay.kt: same changes as Max7219Matrix minus the Job import (LcdDisplay uses job in scrollText but the field declaration moves to base class)
- OledDisplay.kt: same changes as LcdDisplay
</objective>
