## Milestone Summary

### Key Accomplishments

1. **MAX7219 hardware fix** — SPI packet direction corrected; scroll left-to-right confirmed; AbstractDisplayDriver base class eliminated 15 duplicated field declarations across 3 drivers
2. **Scheduler stabilized** — ConflictPolicy enum (SKIP_NEW/INTERRUPT), ONESHOT firedAt atomic update (crash-safe), CRON ERROR persistence, Flyway 9.22.3 migrations; all 4 SCHED requirements covered by automated tests
3. **Full refactor** — DI smoke test guards all 11 bindings; dead config classes removed; ScreenDriverService renamed; 80.7% JaCoCo line coverage; HistoryService layer decouples routes from repository
4. **Display history + webhooks** — Every display event persisted (1000-row cap); paginated/filterable API + HTML; webhook HTTP POST on schedule fire (5s timeout, fire-and-forget)
5. **Multi-zone displays** — ZoneRegistry routes text to local SPI zones and network WebSocket zones; UDP/mDNS autodiscovery; DELETE /zones/{id} for network zones; RFC1918 SSRF protection
6. **Observability gap closures** — GET /health/detail (uptime/memory/display), /metrics hardware group (4 Dropwizard counters), HTML 404/500 pages (SwaggerUI catch-all ordering fixed)
7. **Material 3 UI** — Side navigation, dark mode via prefers-color-scheme, zone selector on send-text, effect preview, Schedule/History/Zones/Status pages all rebuilt

### Key Decisions

| Decision | Rationale |
|----------|-----------|
| buildPacket in companion object | Pure-JVM testable without Pi4J construction |
| Per-row buildPacket signature | Enables 2-byte per-row assertions in Kotest |
| Flyway 9.22.3 (baselineOnMigrate) | Handles existing Pi installs; community license |
| updateFiredAtAndDone single transaction | Crash-safe ONESHOT firedAt+DONE atomic update |
| displayMutex.isLocked for SKIP_NEW | Snapshot read avoids deadlock; false negatives OK |
| ZoneStatus in-memory only | Avoids stale offline status across restarts |
| Single shared Pi4J context + unique IDs | Avoids SPI registration collision on startup |
| HistoryService layer | Prevents direct repository access from routes |
| Material 3 CSS custom properties (no data-theme) | OS dark/light via prefers-color-scheme media query |
| SSR zone selectors | Zones available on page load without extra fetch |
