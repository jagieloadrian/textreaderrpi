# Phase 11.2 Plan 01: IP and DisplayType Validation Migration Summary

Migrated IP validation and display-type validation from route handlers into the Ktor `RequestValidation` plugin; enforced `DisplayType` enum across config models, ConfigLoader, and ZoneRegistry dispatch.

## Tasks Completed

| Task | Name | Commit | Key Files |

| 1 | IP validation migration — delete IpValidation, add AddZoneRequest + plugin validator, flip ZoneRoutes to body | 4d22ed0 | IpValidation.kt (deleted), AddZoneRequest.kt, RequestValidators.kt, RequestValidationConfig.kt, ZoneRoutes.kt, ZoneRoutesTest.kt |
| 2 | DisplayType enum enforcement — config models, ConfigLoader, ZoneRegistry, DisplayRoutes validation | 975d3d1 | DisplayConfig.kt, ZonesConfig.kt, ConfigLoader.kt, ZoneRegistry.kt, DisplayRoutes.kt, RequestValidators.kt, RequestValidationConfig.kt, WebAndDisplayRoutesTest.kt |

## What Was Built

- `IpValidation.kt` deleted (D-01) — its RFC1918 logic migrated to `RequestValidators.validateAddZoneRequest`
- `AddZoneRequest.kt` created as `@Serializable data class AddZoneRequest(val ip: String)` (D-02)
- `RequestValidators.validateAddZoneRequest` + `validateDisplaySelectRequest` added (D-03, D-08)
- `RequestValidationConfig` gains `validate<AddZoneRequest>` and `validate<DisplaySelectRequest>` blocks
- `ZoneRoutes` POST endpoint changed from `post("/{ip}")` path-param to `post {}` body-receive (D-04, D-21)
- `DisplayRoutes` POST /select if-chain (`val normalized/allowed/if !in`) removed; validation in plugin returns 422 (D-09, D-21)
- `DisplayConfig.type` and `ZoneConfig.type` changed `String` → `DisplayType` with `DisplayType.MAX7219` default (D-05, D-07)
- `ConfigLoader` uses private `parseDisplayType(raw)` helper at all 3 sites; UNKNOWN falls back to MAX7219 with warn log (D-22)
- `ZoneRegistry.initLocalZone` dispatches exhaustively on enum cases; passes `.name` to `LocalZoneDriver` (D-06)
- Invalid IP → 422 Unprocessable Entity (was 400 from route handler)
- Invalid driver type → 422 Unprocessable Entity (was 400 from route handler)
