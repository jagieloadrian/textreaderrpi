## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → POST /api/v1/text | Untrusted JSON incl. conflictPolicy crosses into display dispatch |
| client → POST /api/v1/schedule | Untrusted triggerValue (CRON) + webhookUrl cross into persistence + parsing |

## STRIDE Threat Register (ASVS L1)

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-04 | Denial of Service | CRON parsing in ScheduleRoutes POST | mitigate | `cronParser.parse` wrapped in try/catch; invalid expressions persisted as ERROR + 422 rather than crashing the handler or spinning the scheduler loop (SCHED-03). |
| T-07-05 | Input Validation (V5) | webhookUrl in ScheduleValidators | mitigate | `^https?://.*` regex rejects non-http(s) schemes (e.g. `file:`, `gopher:`) with 422 before persist (D-10). Phase 7 stores only — no outbound call yet, so SSRF surface is deferred to Phase 10. |
| T-07-06 | Denial of Service | SKIP_NEW snapshot read of displayMutex.isLocked | accept | `isLocked` is a non-atomic snapshot; false negatives are acceptable for a drop-if-busy policy and never used as a correctness gate (RESEARCH.md Pattern 3 caveat). |
| T-07-07 | Tampering | conflictPolicy enum deserialization | mitigate | Kotlinx serialization restricts values to the `ConflictPolicy` enum; unknown strings fail deserialization with 4xx, never reach dispatch. |
</threat_model>
