<objective>
Fix the SPI packet direction bug in Max7219Matrix.render() so text scrolls left-to-right on a physical 2×8×8 chain. Extract buildPacket() as a pure internal function to make the direction fix unit-testable without Pi4J. Remove the broken size guards in write() and displayStatic(). Add two buildPacket tests to Max7219MatrixTest.

Purpose: The existing render() uses d*8 for column offset, meaning d=0 (first SPI slot, physically rightmost module) renders the leftmost bitmap columns — causing reversed scroll direction. The physicalD fix corrects this in one expression. Extracting buildPacket() enables precise byte-level assertions in the JVM test environment without Pi4J hardware.

Output: Corrected Max7219Matrix.kt and expanded Max7219MatrixTest.kt with two new passing tests.
</objective>
