| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-06-04 | Denial of Service | stop() called concurrently | accept | job?.cancel() is idempotent; Kotlin coroutine cancellation is cooperative and thread-safe. Pre-existing behavior preserved by moving to base class. |
| T-06-05 | Information Disclosure | lastError exposed via status() | accept | status() is part of DisplayDriver interface already; error strings are internal hardware messages, no PII, no credentials. |
| T-06-SC | Tampering | npm/pip/cargo installs | accept | Phase 6 adds zero new packages — no package manager installs occur. |
