<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → POST /api/v1/zones/{ip} | untrusted IP string crosses into a server-side outbound connection |
| LAN → UDP/mDNS replies | untrusted device announcements crossing into discovery |
| Pi → external display (ws://) | outbound WebSocket on the trusted LAN |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-06 | Tampering (SSRF) | POST /api/v1/zones/{ip} | mitigate | Validate IP is IPv4 RFC1918 private range (192.168/16, 10/8, 172.16-31) in the ZoneRoutes handler before any WS connect; reject public IPs with 400. Validation in route handler, not service/repository (project rule). ASVS V5. Test asserts 8.8.8.8 → 400. |
| T-11-07 | Spoofing | UDP/mDNS discovery replies | accept | Discovery is best-effort; a spoofed reply yields a zone that fails the WS connect and falls to OFFLINE. No sensitive data is exposed to the spoofer (Pi only sends display text). Trusted LAN. |
| T-11-08 | Tampering | discovered zone id/ip persisted | mitigate | Persistence uses Exposed parameterized DSL via ZoneRepository.upsert (Plan 01); no raw SQL. ASVS V5. |
| T-11-09 | Information Disclosure | ws:// plaintext frames | accept | Plain ws:// on trusted home LAN; no auth/PII in scope per REQUIREMENTS Out of Scope (V6 N/A). |
| T-11-10 | Denial of Service | JmDNS.create blocking startup | mitigate | JmDNS.create runs inside Dispatchers.IO launch so the ApplicationStarted hook returns immediately (Pitfall 5). |

ASVS controls satisfied: V5 (IPv4 + RFC1918 validation in route handler; parameterized persistence). V6 N/A (plain ws:// accepted on trusted LAN per REQUIREMENTS).
</threat_model>
